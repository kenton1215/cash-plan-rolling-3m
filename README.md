# 💰 智能三个月滚动资金计划系统

面向**研产销一体企业**(研发烧钱、生产备料、销售有账期)的三个月滚动资金计划系统。

企业注册 → 创建各部门操作员 → 各部门在线维护数据或按模块 Excel 模板离线填报 → 规则引擎自动编制 → DeepSeek 大模型智能诊断 → 每月自动滚动更新 → 一键导出 Excel。

> **核心思想**: 不是"预测得准", 而是**提前发现缺口、提前行动**。资金计划从"财务孤军奋战"变成"全公司协同作战"。

---

## 一、核心特性

| 特性 | 说明 |
|---|---|
| 📅 三个月滚动编制 | 始终覆盖未来3个月; 每月月末用实际数替换预测数, 期末实际现金结转下月期初, 向前滚动补充新月份 |
| 👥 多角色协同 | 8种角色(企业管理员/资金专员/销售/采购/研发/人力/行政/管理层), RBAC页面权限+模块数据权限+多企业数据隔离 |
| 📥 双通道数据录入 | **在线编辑**: 表格直接增删改; **Excel通道**: 按业务模块分别下载模板→部门离线填写→专员分模块一键导入(逐行校验/重复跳过)→导入后仍可在线修改 |
| 🤖 大模型智能 | DeepSeek 负责数据校验解读、缺口归因诊断、行动方案建议、管理层报告、情景解读; 未配置Key时自动降级规则引擎, 系统照常运行 |
| ⚙️ 规则引擎兜底 | 回款/采购/汇总计算全部规则化, 结果稳定可靠; 大模型只做"理解、解释、建议" |
| 📥 Excel一键导出 | 计划主表 + 流入/流出明细 + 缺口诊断共4个工作表, 缺口标红, 可直接用于汇报 |
| 🔔 安全底线预警 | 期末现金低于安全底线自动标红并给出缺口金额 |
| 🧪 情景模拟 | 加速回款/新增贷款/推迟资本支出/延后采购付款/压缩费用等 What-If 分析(推迟支出自动顺延至下月重算) |
| 📆 编制日自动生成 | 每月编制日(默认25日)及之后首次访问时, 自动生成下月编制的滚动计划 |

## 三、快速开始

### 1. 环境要求与安装

Python 3.9+, 安装依赖:

```bash
pip install -r requirements.txt
```

### 2. (可选)配置 DeepSeek 大模型

复制 `.env.example` 为 `.env`, 填入 API Key:

```ini
DEEPSEEK_API_KEY=sk-xxxxxxxx        # https://platform.deepseek.com 获取
DEEPSEEK_MODEL=deepseek-chat        # 官方快速模型(即"Flash"级); 也可填 deepseek-reasoner
DEEPSEEK_BASE_URL=https://api.deepseek.com   # 第三方代理时改为代理地址
```

> **关于 DEEPSEEK-FLASH**: DeepSeek 官方快速对话模型名为 `deepseek-chat`(轻量快速, 即"Flash"级定位)。若使用第三方代理(硅基流动/火山方舟等)的 flash 版本, 把 `DEEPSEEK_MODEL` 改为代理方模型名即可。**不配置 Key 系统照常运行**, 智能诊断自动降级为规则引擎版。

### 3. 导入演示数据(可选)

```bash
python init_demo_data.py
```

创建演示企业「演示科技有限公司」+ 8个演示账号 + 完整业务数据(应收4笔/订单4笔/票据2笔/应付4笔/采购预测6笔/工资3月/费用17笔/资本2笔/税务2笔/贷款4笔)。演示场景为缺口逐步扩大(685→1304→2426万元), 适合演示诊断与情景模拟。

### 4. 启动

```bash
streamlit run app.py        # 或双击 run.bat
```

浏览器自动打开 http://localhost:8501

## 六、使用流程(每月循环)

```
每月25日前        各部门更新本部门数据, 两种方式任选:
                  ① 在线编辑: 「数据录入」页直接修改表格(数据简单的推荐)
                  ② Excel填报: 按模块下载模板 → 离线填写 → 交资金专员
                     按模块一键导入(导入后仍可在线修改)
      │
每月25日及之后    系统在首次访问时自动生成下月编制的三个月滚动计划
                  (也可在「资金计划」页手动生成/重新生成)
      │
生成后            资金专员一键「生成智能诊断」→ 缺口归因与行动方案
                  管理层查看看板 → 导出Excel用于汇报
      │
每月月末          资金专员在「数据录入→实际数与期初现金」填写当月实际数
      │
下月编制时        系统自动用实际数替换预测数, 期末实际现金结转下月期初
                  → 向前滚动, 形成新的未来3个月计划
```

## 七、数据编制的两种方式

### 方式一: 在线编辑(简单数据推荐)

「数据录入」页按角色显示有权维护的模块页签, 每个数据表一个在线编辑器:

- 修改单元格后点「💾 保存」(提示新增/修改/删除行数)
- 在表格最后一行填写新数据即可新增; 勾选「🗑 删除」并保存可删除该行
- 资金计划专员可代录所有模块

### 方式二: Excel 模板填报(适合习惯 Excel 的部门)

1. **下载模板**: 按业务模块分别下载(如「销售回款_填报模板.xlsx」), 只发给对应部门; 每个模板含「填写说明」页+该模块各数据表的工作表
2. **离线填写**: 规则写在「填写说明」页 —— 金额单位万元; 日期 `YYYY-MM-DD`、月份 `YYYY-MM`; 比例填0~1(95%填0.95); 勾选项填是/否; 贷款类型填 borrow/repay; 表头不可修改; 空白行自动忽略
3. **分模块导入**: 资金专员选择业务模块 → 上传该模块文件 → 一键导入
4. **导入规则**:
   - 按所选模块和角色权限过滤工作表(其他模块/无权限的表跳过并提示)
   - 逐行校验, 错误行不导入并精确提示"第几行-哪个字段-原因"
   - 普通表追加模式, 与库中完全相同的行自动跳过(**可放心重复导入**)
   - 工资计划/期初现金/月度实际数按月份更新覆盖(空单元格保留原值, 月份必填)
5. **导入后可继续在线编辑修改**

## 八、滚动机制与运算逻辑

```
现金流入 = 应收到期×历史回款率 + 订单回款(发货月+账期)×概率 + 票据到期×兑付率
         + 其他流入(退税/补贴/利息) + 新增借款

现金流出 = 到期应付 + 采购付现(预付当月/余款按账期递延) + 研发试产现款
         + 工资社保 + 费用付现(自动剔除折旧等非付现项) + 资本支出 + 税负 + 偿还借款

净流量 = 流入 - 流出
期末现金 = 期初现金 + 净流量
资金缺口 = max(0, 安全底线 - 期末现金)     ← 安全底线 = 月均刚性付现成本 × 安全系数(1.5~2)

滚动更新: 当月实际数替换预测数 → 期末实际现金结转下月期初 → 补充第4个月预测
```

**研产销企业特性已内置**: 研发试产采购单独列示(通常现款)、客户信用风险按历史回款率打折、税负缴纳时点单独列示、商业承兑按兑付风险打折、非付现费用自动剔除。

**编制日自动生成**: Streamlit 不宜后台定时任务, 采用"访问即生成"策略 —— 每月编制日(系统管理可配置, 默认25日)及之后首次访问时自动生成下月计划并提示。如需严格无人值守, 可配 Windows 计划任务定时访问系统。

## 九、智能诊断(DeepSeek 大模型 + 规则引擎)

| 能力 | 规则引擎 | 大模型增强 |
|---|---|---|
| 数据校验 | 缺失字段/回款率异常/刚性支出缺失等 | 用自然语言说明影响与处理建议 |
| 缺口诊断 | 按缺口月份生成融资/折扣/展期/贴现/压缩等建议(含金额) | 归因分析+风险提示+按优先级排序的行动方案 |
| 文字报告 | 模板化"总体判断/分月要点/应对建议" | 面向管理层的完整资金计划说明 |
| 情景解读 | 逐月对比"原计划→模拟结果" | 解读情景影响与可行性 |

架构原则: **规则引擎负责计算与校验(结果稳定可靠), 大模型负责理解、解释、建议**; API 调用失败或未配置 Key 时自动降级, 系统功能不受影响。

## 十、Excel 导出(计划)

「资金计划」页一键下载, 共4个工作表:

1. **资金计划汇总** — 经典主表: 期初现金/流入明细/流出明细/净流量/期末现金/安全底线/缺口, 缺口与跌破底线标红

3. **现金流出明细** — 逐月逐笔(供应商/采购/工资/费用/资本/税负/还款)
4. **缺口诊断与建议** — 智能诊断全文 + 数据校验问题

## 十一、数据库选型

| 数据库 | 适用场景 |
|---|---|
| **SQLite(默认)** | 单服务器部署、演示、中小规模使用。零安装零配置, 数据在项目目录 `cash_plan.db` |
| PostgreSQL(推荐升级) | 多部门高并发正式生产环境。改 `.env`: `DATABASE_URL=postgresql+psycopg2://user:pass@localhost:5432/cashplan`(需 `pip install psycopg2-binary`) |
| MySQL | 已有MySQL运维体系的企业。改 `.env`: `DATABASE_URL=mysql+pymysql://user:pass@localhost:3306/cashplan`(需 `pip install pymysql`) |

通过 SQLAlchemy ORM 抽象, **切换数据库只需改 `.env` 一行 `DATABASE_URL`**, 代码零修改, 首次启动自动建表; 多企业数据按 company_id 严格隔离。

## 十三、常见问题

**Q: 没有 DeepSeek API Key 能用吗?**
能。计算、汇总、校验、预警全部规则化; 只有"智能诊断/报告"降级为规则引擎版文本。

**Q: Excel 模板与导入有什么规则?**
模板按业务模块分别下载、分别上传导入; 导入按所选模块和角色权限过滤工作表; 逐行校验(金额/比例0~1/月份YYYY-MM/日期/是否), 错误行给出"第几行-哪个字段-原因"且不导入; 普通表追加模式、重复行自动跳过(可放心重复导入); 工资计划/期初现金/月度实际数按月份更新覆盖(空单元格保留原值)。

**Q: 金额单位是什么?**
全系统统一为**万元**, 与财务资金计划惯例一致。

**Q: 多企业能用吗?**
支持。每家企业独立注册, 数据按 company_id 严格隔离, 各自拥有独立操作员、参数与计划。

**Q: "每月自动生成"如何实现?**
编制日(默认25日, 可配置)及之后首次访问系统时自动生成下月计划并提示; 也可手动生成。如需严格定时无人值守, 可配 Windows 计划任务。

**Q: 如何升级到 PostgreSQL?**
`pip install psycopg2-binary`, `.env` 中改 `DATABASE_URL`, 重启即可(自动建表)。
